# ☔ Drizzle Deep

A cozy, lo-fi pixel idle prototype. Rain drips off a roof **on the beat**, wearing the earth away layer by layer, endlessly.

- Drips release on the music's beat grid, and each drip point plays a pentatonic note
- Upgrades: bigger drops, drip rate (drops merge when overflowing), more drip points, splash, rain barrel (idle)
- Weather: Heavy Rain, Acid Rain (×3 vs iron), Lightning (chains through metal), random Storms
- Layers: dirt → clay → stone → iron → crystal → ruins, plus treasure chests and a wandering snail
- Prestige: *Clear Skies* resets for rainbow shards

Single file, no build step: open `index.html`. A tinker panel at the bottom gives you money, storms and a speed boost.
